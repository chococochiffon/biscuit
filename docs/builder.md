# ページビルダーの使い方

ページビルダーは、トップページと固定ページの中身を、ブロックを並べて作る機能です。HTML を書かずに、管理画面の中で公開側に近い見た目を見ながら編集できます。

エディタの中でも、ツールバーの「使い方」から操作の要点を見られます(初めてエディタを開いたときは自動で開きます)。

## エディタを開く

| 編集するもの | 開き方 |
|---|---|
| トップページ | サイドメニューの「トップページ編集」、またはサイト設定の「ページビルダーで編集」 |
| 固定ページ | 固定ページの一覧の「ページビルダーで編集」のボタン(格子のアイコン)、または固定ページの編集画面の「ページビルダーで編集」 |
| 複数のページで使う部品 | サイドメニューの「コンポーネント」で登録して開く([コンポーネント](#コンポーネント)) |

ビルダーで作った内容を公開側に出すには、ビルダーで「公開」したあと、次の設定をオンにします(公開する前は選べません)。

- トップページ: サイト設定の「トップでページビルダーを使う」(公開側のトップのスライダーの下に表示します)
- 固定ページ: 固定ページの編集画面で「ページビルダーで表示する」(詳細の代わりに表示します)

## 画面の見かた

上にツールバー、その下に左から パレット(とツリー)・Canvas・プロパティ が並びます。

- **パレット**(左): 置けるブロックの一覧。「ツリー」タブに切り替えると、ページの入れ子を一覧で見られます。
- **Canvas**(中央): ページの見本。ここでブロックを選び、動かし、大きさを変えます。
- **プロパティ**(右): 選んだブロックの「内容」(文字・画像・リンクなど)、「スタイル」(余白・大きさ・文字・背景・枠線)、「表示」(端末ごとに隠す・表示する期間)を編集します。

## ページの組み立て

ページは **セクション** を縦に並べて作ります。

```
ページ
└─ セクション(背景・高さ・余白)
   ├─ コンテナ(中身の幅をそろえる)
   │  └─ 行
   │     ├─ カラム(幅は 12 分割)── 見出し・テキスト・画像・ボタン…
   │     └─ カラム ─────────────── 見出し・テキスト・画像・ボタン…
   └─ 見出し・テキストなどを直接置くこともできます
```

| まとまり | ブロック |
|---|---|
| レイアウト | セクション・コンテナ・行・カラム |
| 基本 | 見出し・テキスト・画像・ボタン・スペーサー・区切り線・動画(YouTube・Vimeo)・スライダー |
| CMS のデータ | 記事一覧・ナビゲーション・パンくず・ギャラリー(公開側に出すときに、そのときのデータを表示します) |
| コンポーネント | グローバルコンポーネント・独自コンポーネント |

置ける場所が決まっているブロックがあります(ページの直下はセクションだけ、カラムは行の中だけ、スライドはスライダーの中だけ)。置けない場所にはドラッグしても入りません。

迷ったら、ツールバーの「テンプレート」(空のページでは Canvas の「テンプレートから始める」)から近いページを選び、中身を書き換えるのが早道です。

## ブロックを置く・動かす

- **置く**: パレットのブロックを Canvas へドラッグします。青い線が置く位置です。パレットのブロックをクリックすると、選んでいるブロックの近くに追加します。
- **選ぶ**: Canvas のブロックをクリックします。Esc でひとつ外側のブロックを選べます。入れ子が深いときは「ツリー」タブで選ぶと確実です。
- **文字を書き換える**: 見出し・ボタン・テキストをダブルクリックする(または名前の横の鉛筆のボタンを押す)と、Canvas の上で文字をそのまま書き換えられます。テキストは文字を選ぶと太字・リンクなどの書式のバーが出ます。見出し・ボタンは Enter、どれもほかの場所のクリックで終わり、見出し・ボタンは Esc で書き換える前に戻せます。
- **動かす**: 選んだブロックの上に出る名前の部分をドラッグします。名前の横のボタンで、前後への移動・複製・コピー・削除もできます。ツリーの行をドラッグして並べ替えることもできます。
- **コピー・貼り付け**: Ctrl+C / Ctrl+V で、選んだブロックを中身ごと写せます。別のページのエディタへも貼り付けられます。

行にカラムを足すと、カラムの幅を自動で均等にそろえます(幅を自分で変えた行はそろえません)。

## 大きさを変える

ブロックを選ぶと、端につまみが出ます。ドラッグしている間は、変わる値(例:「最小の高さ 320px」「幅 4 / 12」)が表示されます。

| つまみ | 対象 | 変わるもの |
|---|---|---|
| 下の端の丸いつまみ | セクション・スペーサー | 高さ(セクションは最小の高さ) |
| 右の端のつまみ | 画像・コンテナ・動画・スライダー・カラム | 幅(カラムは 12 分割の目盛りに合わせて変わる) |
| 上下の緑の帯 | セクション・コンテナ・カラム | 上・下の内側の余白 |

1 回のドラッグは 1 回の操作として、元に戻す(Ctrl+Z)で戻せます。細かい値は、プロパティの「スタイル」タブで数値を入れても変えられます。

## 端末ごとの見た目

ツールバーのデスクトップ・タブレット・スマートフォンで、Canvas の幅を切り替えて確かめます。

- タブレット・スマートフォンを選んでいるときに変えたスタイル・大きさ・カラムの幅は、**その端末だけ**に効きます。空欄にすると、大きい画面の値を引き継ぎます。
- プロパティの「表示」タブで、端末ごとにブロックを隠せます(すべての端末で隠すことはできません)。
- 同じタブで、表示する期間(開始・終了の日時)も決められます。期間の外のブロックは、公開側には出ません(Canvas では薄く表示します)。

## 保存・プレビュー・公開

- **自動保存**: 変更は、手を止めて 2 秒たつと下書きに保存されます(Ctrl+S や「下書き保存」でもすぐ保存できます)。
- **プレビュー**: 保存してから、公開側の見た目で下書きを新しいタブに表示します。
- **公開**: 下書きを公開側に出します。公開するまで、公開側は前に公開した内容のままです。公開したあとに変えた分は「公開中(未公開の変更あり)」と表示し、「変更を破棄」で公開中の内容に戻せます。
- **版の履歴**: 公開するたびに版が残ります。前に公開した内容を下書きに読み込めます(公開側に出すには、もう一度公開します)。
- **書き出し・読み込み**: ページの内容を画像ごと 1 つのファイルに書き出し、別のページ・別のサイトに読み込めます。

ほかの管理者が同じページを先に保存したときは、上書きせずに知らせます。画面を読み込み直してから続けてください。

## コンポーネント

サイドメニューの「コンポーネント」で、複数のページで使う部品を作れます。

- **グローバルコンポーネント**: ヘッダーやお問い合わせの案内など、どのページでも同じ中身の部品です。コンポーネントを公開すると、使っているすべてのページに反映されます。
- **独自コンポーネント**: 見出しの文字や画像など、使うたびに一部を差し替えられる部品です。部品のエディタで、項目ごとに「使うたびに変えられる項目にする」を選びます。

## テーマと CSS

- サイドメニューの「テーマ」で、ビルダーのブロックに使う色(メイン・サブなど)とフォントを決めます。色のスタイルでテーマの色を選んでおくと、テーマを変えたときに全ページに反映されます。
- スーパー管理者は、ツールバーの「CSS」でページだけに効く CSS を、スタイルのタブでブロックに追加のクラス名を書けます(ビルダーの外へは効きません)。

## キーボードの操作

| キー | 操作 |
|---|---|
| Ctrl + S | 下書き保存 |
| Ctrl + Z | 元に戻す |
| Ctrl + Shift + Z / Ctrl + Y | やり直す |
| Ctrl + C / X / V | 選んだブロックのコピー・切り取り・貼り付け |
| Delete / Backspace | 選んだブロックを削除 |
| Esc | ひとつ外側のブロックを選ぶ(画面を開いているときは閉じる) |

入力欄の中では、元に戻す・コピーなどは入力欄の操作になります。Mac では Ctrl の代わりに Command を使います。
